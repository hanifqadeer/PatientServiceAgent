# Intelligent Enrollment Journey

``` text
Enrollment Document
 -> Salesforce File
 -> OCR / Document Processing
 -> Prompt Builder / AI Structuring
 -> Review LWC
 -> Human Confirmation
 -> Match/Create Patient
 -> Confirm Care Program
 -> Create Patient Support Plan
 -> Assign Coordinator
 -> Create Onboarding Task
```

Potential extracted data: patient identity/contact, communication
preference, program/therapy indicators, HCP, HCO/site and payer
information.

Handle unreadable documents, missing fields, ambiguous extraction,
duplicate Patients, unknown parties, invalid programs and partial
failures.

Use synthetic demo data.
