# Ongoing Support Journey

An active Patient Support Plan is the operational container.

Coordinator reviews plan -\> creates/receives Support Case -\>
Tasks/Events/stakeholder collaboration -\> progress -\> resolution -\>
grounded AI summary reflects trusted activity.

Example Cases: Benefits Verification, Prior Authorization Support,
Reimbursement Assistance, Site of Care Support, Coordination Request,
Education Request, Program Question, General Assistance.
