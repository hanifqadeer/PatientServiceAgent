# Security

Design for least privilege using permission sets and deliberate
record/field access.

Define access for Patient/HCP/HCO, Care Program, Patient Support Plan,
Case, Task/Event, Files and relationship objects.

Decide who can see a Patient/Plan, manager visibility, Case
ownership/queues and how much patient context an FRM truly requires.

Apex must use an intentional sharing/access model. AI receives only the
data needed for its use case.

Demo at least one security scenario where two personas have different
permitted access.
