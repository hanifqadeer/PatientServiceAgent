# Data Cloud

Data Cloud must solve a real data problem; it is not an architecture
decoration.

CRM remains the operational system for Patient Support Plans, Cases,
Tasks and Events.

Proposed demo: ingest one synthetic external dataset, map/use it in Data
Cloud, then expose meaningful unified context or ground an AI
experience.

Candidate dataset: external interaction history, consent/preference
feed, support-channel engagement or program interaction data.

Do not claim Data Cloud is implemented until data is actually ingested,
mapped and consumed.
