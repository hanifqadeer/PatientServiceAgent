# UX

Enterprise architecture should simplify the experience.

-   Enrollment Specialist: `Upload -> Review -> Confirm`.
-   Care Coordinator: `My Plans -> Patient 360 -> Take Action`.
-   FRM:
    `Relevant Access Work -> Stakeholder Context -> Interaction -> Follow-up`.

Patient 360 should surface active Patient Support Plans, selected plan
context, AI summary, Cases, Tasks, Events, Files, relationships and
recent activity.

Prefer standard record pages, related lists, quick actions, reports and
dashboards. Build custom LWC when it materially simplifies a
cross-object workflow. Primary custom candidate: Enrollment Review.
