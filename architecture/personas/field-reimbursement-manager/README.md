# Field Reimbursement Manager (FRM)

## Goal

Collaborate on access/reimbursement needs with HCPs, HCOs, Payers and
Sites of Care.

## Model

FRM participates in relevant Support Cases rather than automatically
owning the entire Patient Support Plan.

``` text
Patient Support Plan -> Access Support Case -> FRM -> HCP/HCO/Payer/Site of Care
```

Record Tasks, Events, interactions and outcomes so the Care Coordinator
retains shared context.
