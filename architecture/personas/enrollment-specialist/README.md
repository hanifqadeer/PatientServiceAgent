# Enrollment Specialist

## Goal

Process enrollment documents quickly and accurately.

## Experience

`Upload -> AI Extract -> Review -> Confirm`

## Workflow

Upload File -\> extraction -\> review/correct -\> match/create Patient
-\> confirm Care Program -\> create Patient Support Plan -\> coordinator
assignment -\> onboarding Task.

## Primary Data

Patient, HCP, HCO, Care Program, Patient Support Plan, Files.

## AI Boundary

Do not silently commit extracted patient/program data. The user reviews
it before authoritative creation/update.
