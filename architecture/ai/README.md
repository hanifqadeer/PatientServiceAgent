# AI Architecture

## Enrollment Extraction

File -\> OCR/document processing -\> AI structuring -\> Review UI -\>
human confirmation -\> Salesforce records.

## Support Summary

Ground summaries in trusted Patient Support Plan, Case, Task, Event and
interaction data. Do not provide diagnosis/prescribing/clinical decision
support.

## Future Assistance

Case classification and "which plans need attention?" assistance may be
added. Operational attention should be grounded in deterministic signals
such as overdue Tasks, priority Cases and upcoming Events.

## AI Coding Requirement

Preserve examples of prompt -\> generated code/artifact -\> learner
review -\> issue found -\> correction -\> test -\> final. The learner's
critical review is part of the project.
