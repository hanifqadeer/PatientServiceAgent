# Roadmap

## MVP

Patient/HCP Person Accounts, HCO Business Accounts, Care Program,
Patient Support Plan, Case, Task, Event, Files, HCP-HCO affiliation,
Patient-HCP relationship, enrollment workflow, coordinator experience,
manager reporting, FRM path, AI extraction/review, AI support summary,
security, one meaningful Flow, justified Apex/LWC and tests.

## Phase 2

Richer payer/site model, Case Stakeholder relationship, advanced
routing/SLA, concrete Data Cloud use case, AI Case classification,
attention assistant, deeper FRM experience and consent/preferences.

## Future

Patient/HCP portals, calendar/activity integration, partner
integrations, advanced analytics, additional programs and a separate
enrollment/application lifecycle if requirements justify it.

Excluded features are product prioritization decisions, not forgotten
work.
