# Integrations

Implement one product-relevant REST integration rather than a random
API.

Pattern:
`Salesforce -> Named Credential/Auth Boundary -> Apex Integration Service -> REST API`.

Learner must understand GET/POST, JSON, authentication, Named
Credentials, status codes, timeout/error handling, retry/idempotency
concepts, logging and callout mocks.

Exact external API remains TBD until a useful journey is selected.
